# Contributing to Gresbase

Pull requests are welcome, under the project's Apache 2.0 license and without a CLA. Large changes
(a new feature, a new dependency, a change of behaviour) start with an issue, to agree on the approach
before writing code.

The full guide, with branches, commits, local CI, translations and how to write the documentation, is
the documentation page [Contributing](site/content/en/contributing.md) ([en español](site/content/es/contributing.md)),
published at `/docs/contributing/` on the Gresbase website.
